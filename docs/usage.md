# 使用指南

## 基本用法

### 升级 Go 版本

```bash
# 在当前目录查找 go.mod
go-mod-select 1.25

# 指定工作目录
go-mod-select 1.25 --dir /path/to/project

# 指定 go.mod 文件路径
go-mod-select 1.25 --gomod /path/to/go.mod
```

### 命令行参数

| 参数 | 说明 |
|------|------|
| `version` | 目标 Go 版本（位置参数） |
| `--dir` | 工作目录（在此目录查找 go.mod） |
| `--gomod` | 直接指定 go.mod 文件路径（优先级最高） |
| `--dry-run` | 仅查看可更新模块，不执行更新 |
| `--auto` | 自动选择所有兼容更新（非交互模式） |
| `--verbose` | 显示详细输出 |

### 工作模式

**三种模式优先级**：
1. **--gomod** 参数（最高） - 使用指定的 go.mod 文件
2. **--dir** 参数 - 在指定目录查找 go.mod
3. **当前目录**（默认） - 在当前目录查找 go.mod

## TUI 界面

### 四个标签页

#### 1. Update 标签页
- 显示有可用更新的模块
- 空格键选择/取消选择
- 颜色表示更新类型（绿=patch, 黄=minor, 蓝=major, 红=prerelease）
- Enter 确认更新选中的模块

#### 2. Require 标签页（只读）
- 显示所有直接依赖（require）
- 空格键查看详情弹窗
- 详情显示：模块信息、使用该包的文件列表

#### 3. Indirect 标签页（只读）
- 显示所有间接依赖（indirect）
- 空格键查看详情弹窗
- 详情显示：模块信息、依赖链（为什么需要此包）

#### 4. Replace 标签页（只读）
- 显示所有 replace 指令
- 空格键查看详情弹窗
- 详情显示：原始模块和替换目标

### 快捷键操作

#### 导航
- `↑` / `↓` 或 `k` / `j` - 上下移动光标
- `PageUp` / `PageDown` - 快速翻页
- `Tab` - 切换标签页

#### 操作
- `Space` - Update 标签页：选择/取消；其他标签页：查看详情
- `Enter` - Update 标签页：确认更新
- `/` - 进入过滤模式，输入关键词实时搜索
- `ESC` - 取消过滤或关闭详情弹窗
- `q` 或 `Ctrl+C` - 退出程序

#### 详情弹窗（只读标签页）
- `↑` / `↓` - 上下滚动内容
- `PageUp` / `PageDown` - 快速翻页
- `ESC` - 关闭弹窗

### 过滤功能

1. 在任意标签页按 `/` 进入过滤模式
2. 输入关键词实时筛选模块
3. 按 `Enter` 应用过滤，按 `ESC` 取消

## 使用场景

### 场景 1：查看可更新的模块

```bash
go-mod-select 1.25 --dry-run
```

只查看哪些模块有更新，不执行更新操作。

### 场景 2：自动更新所有兼容模块

```bash
go-mod-select 1.25 --auto
```

跳过交互界面，自动选择并更新所有与 Go 1.25 兼容的模块。

### 场景 3：查看依赖使用情况

1. 运行 `go-mod-select 1.25`
2. 按 `Tab` 切换到 Require 标签页
3. 选择一个模块，按 `Space` 查看详情
4. 详情弹窗显示哪些 .go 文件使用了该包

### 场景 4：分析间接依赖

1. 按 `Tab` 切换到 Indirect 标签页
2. 选择一个间接依赖，按 `Space` 查看详情
3. 详情弹窗显示完整依赖链（通过 `go mod why` 分析）

### 场景 5：检查 replace 指令

1. 按 `Tab` 切换到 Replace 标签页
2. 查看所有 replace 指令
3. 按 `Space` 查看详细说明

## 工作流程

1. **启动** - 显示欢迎界面和 go.mod 信息
2. **分析** - 并发检查所有依赖的兼容版本
3. **选择** - 在 TUI 界面选择要更新的模块
4. **更新** - 执行更新并显示进度
5. **完成** - 显示更新摘要

## 注意事项

1. **备份** - 更新前会自动备份 go.mod 和 go.sum
2. **回滚** - 更新失败时自动回滚到原始状态
3. **go mod tidy** - 更新完成后会自动运行 `go mod tidy`
4. **网络依赖** - 需要网络连接来查询模块版本
5. **权限** - 需要对 go.mod 和 go.sum 的写权限

## 常见问题

### Q: 某些模块更新失败怎么办？
A: 查看日志文件 `~/.go-mod-select/app.log` 了解详细错误信息。常见原因：
- 网络问题
- 模块已删除或重命名
- goproxy 无法访问

### Q: 如何跳过某些模块？
A: 在 Update 标签页中，不选择该模块即可。

### Q: 更新后程序编译失败怎么办？
A: go-mod-select 会自动回滚。如果已提交，可以手动回滚：
```bash
git checkout go.mod go.sum
```

### Q: 如何查看详细的更新过程？
A: 使用 `--verbose` 参数或查看日志文件。
